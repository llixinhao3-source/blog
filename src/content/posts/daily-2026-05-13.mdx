## 技术笔记

### Hexo CLI 找不到项目的根因
```
hexo-cli 的 find_pkg() 往上遍历目录找 package.json 中的 hexo 字段
如果 package.json 里没有 "hexo": {...} 这个字段，hexo 不会被识别为有效 Hexo 项目
解决：加 "hexo": { "version": "x.x.x" } 到 package.json
```

### YAML 缩进检测技巧
```bash
sed -n '44,52p' file.yml | od -c   # 看字符的八进制，看空格还是 tab
python3 -c "import yaml; yaml.safe_load(open('file.yml'))"  # Python 可以快速验证
```

### npm 本地安装替代全局
```bash
# 不用 sudo npm install -g
# 直接在项目目录 npm install
cd ~/blog && npm install hexo-cli
./node_modules/.bin/hexo g   # 直接用本地 binary
```

### Butterfly 主题依赖
```bash
npm install hexo-renderer-pug hexo-renderer-stylus
git clone https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly
cd themes/butterfly && npm install
```
