## 背景

在物联网应用中，WiFi 通信是 ESP32-S3 最核心的功能之一。本文将详细讲解如何利用 ESP32-S3 的 WiFi 模块实现稳定的网络通信。

## WiFi 初始化

```c
#include "esp_wifi.h"
#include "esp_event.h"
#include "nvs_flash.h"

void wifi_init_sta(void)
{
    nvs_flash_init();
    esp_netif_init();
    esp_event_loop_create_default();
    esp_netif_create_default_wifi_sta();

    wifi_init_config_t cfg = WIFI_INIT_CONFIG_DEFAULT();
    esp_wifi_init(&cfg);

    wifi_config_t wifi_config = {
        .sta = {
            .ssid = "YOUR_SSID",
            .password = "YOUR_PASSWORD",
        },
    };

    esp_wifi_set_mode(WIFI_MODE_STA);
    esp_wifi_set_config(WIFI_IF_STA, &wifi_config);
    esp_wifi_start();
}
```

## SmartConfig 配网

对于没有输入界面的 IoT 设备，SmartConfig 是一种优雅的配网方案：

```c
void smartconfig_example_task(void *param)
{
    esp_smartconfig_set_type(SC_TYPE_ESPTOUCH);
    smartconfig_start_config_t cfg = SMARTCONFIG_START_CONFIG_DEFAULT();
    esp_smartconfig_start(&cfg);

    while (1) {
        smartconfig_event_status_t status;
        esp_smartconfig_get_status(&status);
        if (status == SC_STATUS_LINK_OVER) {
            esp_smartconfig_stop();
            break;
        }
        vTaskDelay(1000 / portTICK_PERIOD_MS);
    }
}
```

## MQTT 通信

```c
#include "mqtt_client.h"

static void mqtt_event_handler(void *arg, esp_event_base_t base,
                                int32_t event_id, void *event_data)
{
    esp_mqtt_event_handle_t event = event_data;
    switch (event->event_id) {
        case MQTT_EVENT_CONNECTED:
            ESP_LOGI(TAG, "MQTT connected");
            esp_mqtt_client_subscribe(client, "/device/command", 1);
            break;
        case MQTT_EVENT_DATA:
            ESP_LOGI(TAG, "Received: %.*s", event->data_len, event->data);
            break;
    }
}
```
