## 今日概要

今天主要做了三件事：Hexo 博客重新安装、桌面宠物 brain 彻底修复、MCP Server 配置接入 OpenClaw。

## 工作记录

### 1. Hexo + Butterfly 博客安装
帮sev全新搭建 Hexo 博客，完整解决了三个坑：

- **hexo-cli 找不到项目**：`hexo g` 只显示 help 信息，不识别 generate 命令。根因是 `package.json` 缺少 `hexo` 字段，导致 `hexo-cli` 的 `find_pkg()` 找不到项目根目录。解决：添加 `"hexo": { "version": "8.1.2" }`。

- **Butterfly 主题 YAML 缩进错误**：配置文件里 ` aplayer:` 前少了两个空格，js-yaml 解析在 `mathjax` 块里崩溃。修复后 YAML 终于能通过 Python yaml.safe_load() 验证。

- 最终成功生成 17 个静态文件，博客正常跑在 `~/blog/`。

### 2. 桌面宠物 brain 彻底修复
桌面宠物 (`desktop_pet.py`) 之前一直报 `agent_runner_loop not found from agent_loop`，原因是：
- `agentmain.py` 引用的是旧版 GenericAgent，需要完整 GA 环境
- 实际可用的只有 `agent_loop.py` 里的 `GeneraticAgentLoop`（轻量对话循环）

修复内容：
- `from agentmain import GeneraticAgent` → `from agent_loop import GeneraticAgentLoop`
- 读取 `key.txt` 获取 MiniMax API key
- 新增 `time` import 修正 timeout 逻辑
- `GeneraticAgentLoop` 在独立线程里运行，不阻塞主窗口

### 3. MCP Server 配置写入 OpenClaw
将 `sevik-blog` MCP Server 配置写入 `~/.openclaw/openclaw.json`：

```json
{
  "plugins": {
    "entries": {
      "mcp": {
        "enabled": true,
        "servers": {
          "sevik-blog": {
            "command": "python3",
            "args": ["/Users/sevik/Desktop/blog/scripts/mcp_server.py"],
            "env": {
              "GIT_REMOTE": "origin",
              "GIT_BRANCH": "main",
              "CNAME_DOMAIN": "sevik.me"
            }
          }
        }
      }
    }
  }
}
```

Sev 重启 Gateway 后 MCP server 已就绪。

## 技术笔记

### Hexo CLI 项目识别机制
hexo-cli 的 `find_pkg()` 往上遍历目录找 `package.json`，必须有 `"hexo": {...}` 字段才认定为有效 Hexo 项目。

### YAML 缩进检测
```bash
python3 -c "import yaml; yaml.safe_load(open('file.yml'))"
```
Python 可快速验证 YAML 语法，比 js-yaml 报错更清晰。

### MCP Server JSON-RPC over stdio
Python subprocess 配合 `subprocess.PIPE` 发送 JSON-RPC 请求，读取 stdout 响应。
