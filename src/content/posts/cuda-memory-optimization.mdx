## 内存访问的重要性

GPU 的计算能力远超内存带宽。在 CUDA 编程中，内存访问模式往往是性能瓶颈。本文将介绍三种关键的内存优化技术。

## 全局内存合并访问

### 非合并访问（性能差）

```cuda
__global__ void nonCoalesced(float *data, int width)
{
    int row = blockIdx.x * blockDim.x + threadIdx.x;
    // 线程访问不连续的内存地址
    float val = data[col * width + row];
}
```

### 合并访问（性能好）

```cuda
__global__ void coalesced(float *data, int width)
{
    int col = blockIdx.x * blockDim.x + threadIdx.x;
    // 相邻线程访问相邻地址
    float val = data[col];
}
```

## 共享内存 Bank Conflict

共享内存被分为 32 个 bank（对应 32 个线程的 warp），每个 bank 每周期可服务一个地址。

### Bank Conflict 示例

```cuda
__global__ void bankConflict(float *in, float *out)
{
    __shared__ float shared[32][32];
    int tid = threadIdx.x;

    // 32个线程访问同一 bank 的不同地址 → 32-way bank conflict
    float val = shared[tid][0];
}
```

### 消除 Bank Conflict

```cuda
__global__ void noBankConflict(float *in, float *out)
{
    __shared__ float shared[32][33]; // 填充一列避免冲突
    int tid = threadIdx.x;

    // 无 bank conflict
    float val = shared[tid][0];
}
```

## 常量内存优化

```cuda
__constant__ float filter[256];

__global__ void convolution(float *input, float *output, int n)
{
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    float sum = 0;

    // 常量内存通过 cache 广播，warp 内所有线程同时访问同一地址
    for (int i = 0; i < 256; i++) {
        sum += input[idx + i] * filter[i];
    }
    output[idx] = sum;
}
```

## 性能对比

| 优化技术 | 提升倍数 |
|---------|---------|
| 合并访问 vs 非合并 | 10-20x |
| 消除 Bank Conflict | 2-3x |
| 常量内存 vs 全局内存 | 3-5x |

## 小结

内存优化是 CUDA 性能调优的核心。理解 GPU 的内存架构和访问模式，能够帮助写出高效的 CUDA 程序。
