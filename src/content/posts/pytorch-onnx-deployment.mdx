## 概述

模型部署是将训练好的模型从实验室推向生产环境的关键环节。本文将记录我在工业实习中的模型部署实践经验。

## PyTorch 模型导出

```python
import torch
import torch.onnx

model = MyDetectionModel()
model.load_state_dict(torch.load('best_model.pth'))
model.eval()

dummy_input = torch.randn(1, 3, 640, 640)

torch.onnx.export(
    model,
    dummy_input,
    'model.onnx',
    opset_version=17,
    input_names=['input'],
    output_names=['output'],
    dynamic_axes={
        'input': {0: 'batch'},
        'output': {0: 'batch'}
    }
)
```

## ONNX 模型验证与优化

import onnx
