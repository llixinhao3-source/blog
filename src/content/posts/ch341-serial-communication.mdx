## CH341 简介

CH341 是南京沁恒微电子推出的 USB 总线转接芯片，支持 USB 转串口、并口、I2C 等多种模式。在嵌入式开发中，CH341 被广泛用作 USB-TTL 转换器。

## 硬件连接

```
ESP32-S3          CH341
---------        --------
GPIO43 (TX)  ->  RXD
GPIO44 (RX)  ->  TXD
GND          ->  GND
3.3V         ->  VCC
```

## UART 配置

```c
#include "driver/uart.h"

#define UART_NUM        UART_NUM_1
#define TXD_PIN         GPIO_NUM_43
#define RXD_PIN         GPIO_NUM_44
#define BUF_SIZE        2048

void uart_init(void)
{
    uart_config_t uart_config = {
        .baud_rate = 921600,
        .data_bits = UART_DATA_8_BITS,
        .parity = UART_PARITY_DISABLE,
        .stop_bits = UART_STOP_BITS_1,
        .flow_ctrl = UART_HW_FLOWCTRL_DISABLE,
    };

    uart_param_config(UART_NUM, &uart_config);
    uart_set_pin(UART_NUM, TXD_PIN, RXD_PIN,
                 UART_PIN_NO_CHANGE, UART_PIN_NO_CHANGE);
    uart_driver_install(UART_NUM, BUF_SIZE * 2, 0, 0, NULL, 0);
}
```

## 高速数据传输

### 环形缓冲区设计

```c
typedef struct {
    uint8_t *buffer;
    size_t size;
    size_t head;
    size_t tail;
} ring_buffer_t;

int ring_buffer_write(ring_buffer_t *rb, uint8_t *data, size_t len)
{
    for (size_t i = 0; i < len; i++) {
        size_t next = (rb->head + 1) % rb->size;
        if (next == rb->tail) return -1; // 缓冲区满
        rb->buffer[rb->head] = data[i];
        rb->head = next;
    }
    return 0;
}
```

### DMA 传输优化

```c
void uart_dma_send(uint8_t *data, size_t len)
{
    // 使用 DMA 减少 CPU 干预
    uart_write_bytes_with_break(UART_NUM, data, len, 0);
}
```

## 性能测试

| 波特率 | 实际吞吐量 | CPU 占用 |
|--------|-----------|---------|
| 115200 | ~11 KB/s | `&lt;1%` |
| 921600 | ~88 KB/s | ~3% |
| 2000000 | ~190 KB/s | ~8% |

## 常见问题

1. **数据丢失**：检查缓冲区大小是否足够
2. **波特率偏差**：ESP32-S3 使用 APB 时钟，某些波特率可能存在偏差
3. **驱动兼容性**：macOS 上 CH341 需要安装特定驱动

## 小结

CH341 配合 ESP32-S3 的硬件 UART 可以实现高效稳定的串口通信。在需要高速数据传输的场景下，DMA + 环形缓冲区是最佳实践。
