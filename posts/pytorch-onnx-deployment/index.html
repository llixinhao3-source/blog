PyTorch 模型部署实战：从训练到 ONNX 推理优化

记录工业级 PyTorch 模型部署的完整流程，包括 ONNX 导出、推理引擎优化与性能基准测试。

#PyTorch #ONNX #模型部署 #推理优化 #工业级

概述

模型部署是将训练好的模型从实验室推向生产环境的关键环节。本文将记录我在工业实习中的模型部署实践经验。

PyTorch 模型导出

import torch
import torch.onnx

model = MyDetectionModel()
model.load_state_dict(torch.load('best_model.pth'))
model.eval()

dummy_input = torch.randn(1, 3, 640, 640)

torch.onnx.export(
    model,
    dummy_input,
    'model.onnx',
    opset_version=17,
    input_names=['input'],
    output_names=['output'],
    dynamic_axes={
        'input': {0: 'batch'},
        'output': {0: 'batch'}
    }
)

模型服务化

from fastapi import FastAPI
import onnxruntime as ort

app = FastAPI()
session = ort.InferenceSession('model.onnx')

@app.post("/predict")
async def predict(data: InputData):
    input_tensor = preprocess(data)
    outputs = session.run(None, {'input': input_tensor})
    return postprocess(outputs)

小结

ONNX 作为模型交换格式，配合 ONNX Runtime 可以实现跨硬件平台的高效推理。TensorRT 在 NVIDIA GPU 上提供了最佳的推理性能。
